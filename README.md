# Data Scientist Portfolio

A Next.js portfolio site for data science, machine learning, and agricultural technology work.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion

## Deploy

The app is set up for Vercel. Run `npm run build` locally to verify a production build.
